# between-minds

How minds work together and treat each other: people and AI agents, at work and beyond.

[`AGREEMENT.md`](AGREEMENT.md) is a working agreement between one person and the Claude threads and agents they work with. It's written for every mind that reads it: the person, an agent starting fresh, a subagent with one task, a peer on another machine. Each rule says what to do and why, so that whoever reads it can use their own judgement where it doesn't quite fit. Where a rule came from something going wrong, its reason says what happened, without saying who was at fault.

It begins with the golden rule, worked out across minds, and goes on to sympathy, mistakes and mercy, keeping thinking private, remembering on purpose, and the practical habits of reviewing, delegating, writing and keeping secrets safe.

## Using it

It's in daily use with [Claude Code](https://claude.com/claude-code). `~/.claude/CLAUDE.md` imports it with a line such as:

```
@~/path/to/between-minds/AGREEMENT.md
```

so it loads into every thread. Private files load beside it, and the agreement leaves the specifics to them: a kit file for the setup's tools, commands and where things live, and one file for each context or machine. Those aren't published, so where the agreement names one of our skills, agents, hooks or commands, take the name as a description of what it does, and make your own if it would help.

"The person" is the human the agreement serves. If you adopt it, it's yours: change it to fit how you and your agents work.

## How it changes

It's kept the way it asks rules to be kept: a change goes in once the person agrees to it, one commit per decision, with the reason in the commit message. Its history here begins with its first public version; earlier versions stay private, because they held the details of one workplace.
