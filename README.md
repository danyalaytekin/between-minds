# between-minds

How minds work together and treat each other: people and AI agents, at work and beyond.

This repository is for the public version of a working agreement, written for every mind that reads it: a person, an agent starting fresh, a subagent with one task, a peer on another machine. Each rule says what to do and why, so that whoever reads it can use their own judgement where it doesn't quite fit.

It is private for now, and nothing has been published yet. The agreement is kept in a private working copy, and reviewed versions will be copied here.

## Names we considered

`between-minds` is the name chosen, for now. The others may still find a use, perhaps as file names:

- `between-minds`: what the agreement is about, for people and agents alike.
- `trellis`: a structure that supports growth without forcing its shape.
- `common-ground`: the shared basis minds stand on together.
- `how-we-work`: plain and easy to find.
- `accord`, `minds-accord`, `the-accord`: an agreement entered into willingly.
- `covenant`: a binding promise, with an older and more solemn ring.
- `prologue-for-intelligence`: the title of a book not yet begun.
